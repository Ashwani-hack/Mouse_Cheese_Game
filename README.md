# 🧀 Mouse & Cheese Maze Game 🐭

A simple and fun browser-based maze game where the player controls a mouse and tries to reach the cheese while navigating through a maze.

## 🎮 Game Overview

The **Mouse & Cheese Maze Game** is a lightweight HTML, CSS, and JavaScript game created for practicing web development and JavaScript game logic.

The objective is simple:

> 🐭 Guide the mouse through the maze and reach the 🧀 cheese!

Avoid getting stuck and find the correct path through the maze.

## ✨ Features

- 🐭 Interactive mouse character
- 🧀 Cheese as the game objective
- 🌀 Maze-based gameplay
- ⌨️ Keyboard controls
- 🎨 Simple and attractive game interface
- 🌐 Runs directly in a web browser
- ⚡ No backend or database required
- 📱 Lightweight and easy to run

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactions
- **PNG / AVIF Images** – Game graphics
